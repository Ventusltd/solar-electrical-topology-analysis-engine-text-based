Geometry

Row span = N × width + (N−1) × gap. No user-entered string length exists.

Wiring and line geometry

Differential and common-mode paths remain separate. Installed formation remains unresolved until traced or measured.

Complete series circuit

4 mm² module leads and 6 mm² home-runs are calculated separately. Connector count is expressed as mated interfaces.

Module capacitance to frame / earth

Wet state uses full module area. Dry state uses a defaulted perimeter strip and probably understates fringing and rear-rail coupling.

Module voltage

The output prints cold Voc, remaining margin and the calculated temperature at which the system maximum is breached.

Plant basis

The 24-string drawing is a fully populated archetype. The fleet average is actual strings ÷ installed inverters.
