String geometry

Strings and inverter distance

Each comma-separated number is the string count in one equal-distance archetype band.

Inverter distance changes the unavoidable positive-and-negative base pair. It does not change the one-row-span return eliminated by feasible leapfrog wiring.

External 6 mm² DC string cable

Fleet saving is calculated from actual total site strings, not by assuming every inverter carries the 24-string archetype.

Factory module-lead feasibility

Without a measured override, required leapfrog reach is two module pitches. Savings are unavailable when the lead-length screen fails.

Why leapfrog removes the far-end EPC return

          

            

              Sequential wiring places the two free string terminals at
              opposite physical ends. Leapfrog brings both to the
              inverter-side end. The diagram is a topology explanation;
              feasibility is controlled separately by the lead gate.

Technical commentary governing V8.2

          

            

              A string always has one free positive terminal and one free
              negative terminal. Leapfrog changes their physical location,
              not the string voltage, current, module count or MPPT duty.
            

            

              Sequential wiring requires an unavoidable base pair plus one
              additional row-length return conductor per string. Feasible
              leapfrog wiring retains the base pair and removes the row
              return.
            

            

              Factory module leads are in circuit under both topologies.
              They are not saved copper. Only external EPC-installed cable
              differs unless extension leads are required.
            

            

              The lead screen uses two module pitches unless measured route
              evidence is entered. When it fails, V8 refuses to report the
              theoretical cable difference as an available saving.
            

            

              Site totals use actual total string count. The 24-string
              inverter remains an archetype and is not multiplied blindly
              by inverter count.
