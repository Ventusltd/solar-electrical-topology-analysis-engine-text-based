External 6 mm² DC string cable

Technical commentary governing V8.2

          

            

              A string always has one free positive terminal and one free
              negative terminal. Leapfrog changes their physical location,
              not the string voltage, current, module count or MPPT duty.
            

            

              Sequential wiring requires an unavoidable external base pair
              plus one additional field-installed row-length return conductor
              per string. Feasible leapfrog wiring retains the external base
              pair and removes that field-installed return.
            

            

              Factory module leads remain in circuit under both topologies,
              but the total factory-fitted interconnect path is not the same.
              Build 025 shows that the increased factory-fitted path can exceed
              the field-installed reduction, producing a small increase in
              total circuit conductor while substantially reducing EPC cable.
            

            

              The lead screen uses two module pitches unless measured route
              evidence is entered. When it fails, V8 refuses to report the
              theoretical external-cable difference as available.
            

            

              V8 resistance, voltage-drop and loss differences apply only to
              the represented external 6 mm² conductor. They are not complete
              circuit results and must not be promoted as total-system loss
              reduction.
            

            

              Site totals use actual total string count. The 24-string
              inverter remains an archetype and is not multiplied blindly
              by inverter count.
