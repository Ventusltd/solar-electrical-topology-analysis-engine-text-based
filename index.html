Plant basis

Default fleet basis: 900 inverters · 18,918 strings · 24-input hardware ceiling. The selected 24-string drawing is an archetype, not a claim that every inverter is full.

Complete series circuit

Connector count is graph-derived: N−1 inter-module pairs + additional interfaces. Resistance basis must match the evidence source.

Coiled surplus scenario

Default coil count is zero. Add only from measured or drawing-derived evidence. Coil calculations are screening approximations.

Electrical and temperature

Default R20 values represent flexible tinned copper screening inputs. Replace with the controlled cable datasheet.

Loop and common-mode geometry
